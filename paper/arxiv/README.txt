Matter that pays the price of perfection
Seth Douglas and Nidhal Mghirbi
Version 1.0.0, October 2026. A preprint; it has not been peer reviewed.

This folder contains all manuscript sources and finite checks.
Compile directly with pdflatex main, bibtex main, and three further pdflatex passes.
Alternatively use python build.py --output-dir BUILD_DIRECTORY in a separate folder.
Run python check_artifacts.py for source and checksum consistency.
The complete game-driven material theorem has explicit layout and selection
hypotheses. The source and finite checks have the scope stated in the manuscript.

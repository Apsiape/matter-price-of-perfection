Matter that pays the price of perfection
Seth Douglas and Nidhal Mghirbi
Version 1.0.0, October 2026. A preprint; it has not been peer reviewed.

main.pdf is the manuscript. main.tex inputs the named section files.
references.bib and main.bbl provide the bibliography.
Build in a separate directory: python build.py --output-dir BUILD_DIRECTORY
The builder runs pdflatex, BibTeX and three further pdflatex passes, then rejects
final-pass warnings, undefined references and overfull or underfull boxes.
arxiv/ is a self-contained source package. anc/ contains all finite checks.
Run python check_artifacts.py to check source consistency and ancillary hashes.
The complete game-driven material theorem has explicit layout and local
positive-energy selection hypotheses. Its local realization remains conditional.
Thermodynamic distinct-level gaps use factorial tori before the coupling limit.
Entanglement observables use the stated single-block, off-tie, growing sub-cell cut.
